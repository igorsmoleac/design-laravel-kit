Tutti i componenti di design-laravel-kit. Questa pagina è realizzata interamente con i componenti del pacchetto.

Layout

Pagina completa: <x-italia::layout> combina l'header (slim + center + navbar), un contenitore principale con skip link accessibile e un footer. Questa pagina è renderizzata tramite <x-italia::layout>: l'header in alto e il footer in fondo sono demo interattive.

Mostra il codice 
<x-italia::layout title="Titolo della pagina" :slim="[...]" :center="[...]" :navbar="[...]" :footer="[...]">
    <x-slot:breadcrumbs>...</x-slot:breadcrumbs>
    Contenuto della pagina
</x-italia::layout>

Header

Header a tre livelli: HeaderSlim (ente + link + lingue + accesso), HeaderCenter (brand + tagline + social + ricerca), HeaderNavbar (menu con dropdown). L'header in cima a questa pagina mostra i tre livelli combinati tramite <x-italia::header>.

Mostra il codice 
<x-italia::header-slim ente="Comune di Roma" :links="[...]" :languages="[...]" loginUrl="/login" />
<x-italia::header-center title="Comune di Roma" tagline="Portale istituzionale" :logo="..." :socialLinks="[...]" searchUrl="/search" />
<x-italia::header-navbar :items="[['text' => 'Home', 'url' => '/', 'active' => true], [..., 'dropdown' => [...]]]" />

// Oppure combina tutti e tre insieme:
<x-italia::header :slim="[...]" :center="[...]" :navbar="[...]" />

Footer

Footer istituzionale con sezioni di link, contatti (indirizzo, telefono, email, PEC), social e barra legale. Il footer in fondo a questa pagina è una demo interattiva.

Mostra il codice 
<x-italia::footer
    title="Comune di Roma"
    subtitle="Portale istituzionale"
    :sections="[['title' => 'Amministrazione', 'links' => [...]]]"
    :contacts="[['type' => 'address', 'value' => '...'], ['type' => 'phone', 'value' => '...'], ['type' => 'email', 'value' => '...'], ['type' => 'pec', 'value' => '...']]"
    :social-links="[['url' => '...', 'icon' => 'it-facebook', 'label' => 'Facebook']]"
    :legal-links="[['url' => '/privacy', 'text' => 'Informativa sulla privacy', 'dataElement' => 'privacy-policy-link']]"
/>

Modal

Finestra di dialogo con focus trap automatico (JS di Bootstrap Italia) e supporto ARIA completo. Si apre con data-bs-toggle="modal" e data-bs-target="#id" su qualsiasi pulsante o link.

Conferma azione

Sei sicuro di voler procedere con questa operazione?

Modal con descrizione ARIA

Questo testo è collegato all'attributo aria-describedby della modale, per gli screen reader.

Il parametro description è opzionale. Se specificato, viene collegato all'attributo aria-describedby e letto dagli screen reader all'apertura. Se omesso, l'attributo non viene emesso — la modale non forza la lettura completa del body.

Modal grande

Contenuto più ampio della modal standard.
Mostra il codice 
<x-italia::button data-bs-toggle="modal" data-bs-target="#my-modal">Apri</x-italia::button>

<x-italia::modal id="my-modal" title="Conferma">
    Sei sicuro?
    <x-slot:footer>
        <x-italia::button>Conferma</x-italia::button>
        <x-italia::button variant="outline" data-bs-dismiss="modal">Annulla</x-italia::button>
    </x-slot:footer>
</x-italia::modal>

<x-italia::button data-bs-toggle="modal" data-bs-target="#demo-modal-description">
    Apri modal con descrizione
</x-italia::button>

<x-italia::modal
    id="demo-modal-description"
    title="Modal con descrizione ARIA"
    description="Questo testo è collegato all'attributo aria-describedby della modale, per gli screen reader."
    size="lg"
    centered
>
    Il parametro description è opzionale e viene collegato all'attributo aria-describedby.
</x-italia::modal>

// Varianti
<x-italia::modal title="..." size="lg" centered />
<x-italia::modal title="..." size="xl" scrollable />
<x-italia::modal title="..." static />
