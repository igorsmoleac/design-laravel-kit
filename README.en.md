Design Laravel Kit is a Composer package for Laravel applications in the Italian Public Administration. It provides Blade components based on Bootstrap Italia 2.18.3 for institutional layouts, navigation, forms, messages, and SPID and CIE access. The distributed bundle is approximately 250 KB gzip; Node.js is needed only to build the package assets.

It is intended for digital agencies, system integrators, and developers building websites and digital services for public bodies. The package provides components and assets; the integrating project remains responsible for verifying compliance of the service as a whole.

## Characteristics

- Blade components based on Bootstrap Italia `2.18.3`
- Three-tier institutional header: slim, center, and navbar
- Footer with sections, contacts, legal links, and `data-element` attributes
- Form fields with Laravel validation error and old-input binding
- ARIA attributes, generated identifiers, and a skip-to-content link in the layout
- SPID and CIE login buttons with their respective logos
- CSS, JavaScript, font, and SVG sprite assets published through Artisan
- Declared compatibility with Laravel 12 and 13 and PHP 8.3

## Requirements

| Component | Version |
|-----------|---------|
| PHP | `^8.3` |
| Laravel | `^12.0 \| ^13.0` (`illuminate/support`, `illuminate/view`) |
| Node.js (asset builds only) | `^22.0` |
| Bootstrap Italia | `2.18.3` (pinned) |

Node.js is not required by the running Laravel application. It is used only to build the package assets during package development.

## Installation

```bash
composer require igorsmoleac/design-laravel-kit
php artisan design-laravel-kit:install
```

The `install` command publishes the configuration and the CSS, JavaScript, font, and SVG sprite assets to `public/vendor/design-laravel-kit/`.

Add the directives to the Blade layout:

```blade
<head>
    @designLaravelKitStyles
</head>
<body>
    @designLaravelKitScripts
</body>
```

To publish the configuration separately:

```bash
php artisan vendor:publish --tag=design-laravel-kit-config
```

To update the package, run `composer update igorsmoleac/design-laravel-kit` and republish the assets:

```bash
php artisan design-laravel-kit:publish-assets --force
```

The `--force` option overwrites already published assets.

## Configuration

The `install` command publishes `config/design-laravel-kit.php`. If the configuration file already exists, Laravel does not overwrite it. To force publishing it:

```bash
php artisan vendor:publish --tag=design-laravel-kit-config --force
```

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `id_prefix` | `string` | `'dlk'` | Prefix for HTML IDs generated by components |
| `assets_path` | `string` | `'vendor/design-laravel-kit'` | Public path for assets |
| `version` | `string` | `'0.1.0'` | Version appended to asset URLs for cache busting |

### Translations

The package includes Italian and English translation files. To customize them or add other languages:

```bash
php artisan vendor:publish --tag=design-laravel-kit-lang
```

The files will be copied to `lang/vendor/design-laravel-kit/`.

## Usage

### Institutional layout

Configure the institution, navigation, legal links, and page content:

```blade
<x-italia::layout
    title="Comune di Roma — Portale istituzionale"
    :slim="[
        'ente' => 'Comune di Roma',
        'enteUrl' => 'https://www.comune.roma.it',
        'loginUrl' => '/login',
    ]"
    :center="[
        'title' => 'Comune di Roma',
        'tagline' => 'Portale istituzionale',
        'url' => '/',
        'searchUrl' => '/cerca',
    ]"
    :navbar="[
        'items' => [
            ['text' => 'Amministrazione', 'url' => '/amministrazione'],
            ['text' => 'Servizi', 'url' => '/servizi'],
        ],
    ]"
    :footer="[
        'title' => 'Comune di Roma',
        'legalLinks' => [
            ['url' => '/privacy', 'text' => 'Privacy policy', 'dataElement' => 'privacy-policy-link'],
            ['url' => '/accessibilita', 'text' => 'Dichiarazione di accessibilità', 'dataElement' => 'accessibility-link'],
        ],
    ]"
>
    <h1>Servizi comunali</h1>
    <p>Informazioni e servizi per i cittadini.</p>
</x-italia::layout>
```

### Service request form

Form components bind Laravel session errors and restore previous input after an invalid submission:

```blade
<form method="POST" action="{{ route('segnalazioni.store') }}">
    @csrf
    <x-italia::input name="email" type="email" label="Indirizzo email" required />
    <x-italia::textarea name="messaggio" label="Descrizione della segnalazione" :rows="5" required />
    <x-italia::button type="submit">Invia segnalazione</x-italia::button>
</form>
```

### Header in an existing view

Use the header component without adopting the layout component:

```blade
<x-italia::header
    :slim="['ente' => 'Azienda sanitaria locale']"
    :center="['title' => 'Servizi sanitari', 'searchUrl' => '/cerca']"
    :navbar="['items' => [['text' => 'Prenotazioni', 'url' => '/prenotazioni']]]"
/>
```

### Loading button

Set `loading` while a request is being submitted:

```blade
<x-italia::button type="submit" loading>
    Invio della richiesta in corso
</x-italia::button>
```

## Components

Blade components use the `<x-italia::` prefix.

| Component | Description |
|-----------|-------------|
| `<x-italia::layout>` | Page layout with header, content, footer, and skip-to-content link |
| `<x-italia::header>` | Header composed of slim, center, and navbar tiers |
| `<x-italia::footer>` | Footer with sections, contacts, social links, and legal links |
| `<x-italia::icon>` | Icon from the Bootstrap Italia SVG sprite |
| `<x-italia::button>` | Button or link with variants, sizes, and loading state |
| `<x-italia::input>` | Input field with label, hint, and error binding |
| `<x-italia::select>` | Dropdown with options, optgroups, and multiple selection |
| `<x-italia::textarea>` | Multi-line field with error binding |
| `<x-italia::checkbox>` | Single checkbox |
| `<x-italia::radio>` | Single radio button |
| `<x-italia::checkbox-group>` | Checkbox group with fieldset and legend |
| `<x-italia::radio-group>` | Radio group with fieldset and legend |
| `<x-italia::alert>` | Status message: info, success, warning, or danger |
| `<x-italia::badge>` | Status label with configurable variant |
| `<x-italia::card>` | Card with content, optional link, and variants |
| `<x-italia::spinner>` | Loading indicator with configurable accessible label |
| `<x-italia::modal>` | Dialog with ARIA attributes and Bootstrap Italia JavaScript support |
| `<x-italia::spid-button>` | SPID login button |
| `<x-italia::cie-button>` | CIE login button |

Component examples are in the [playground catalog](https://github.com/igorsmoleac/design-laravel-kit/blob/main/playground/resources/views/catalog.blade.php), which is used during development.

## Accessibility

Components include skip-to-content links, labels associated with form fields, ARIA attributes for form errors, and `data-element` attributes for footer legal links. WCAG 2.1 Level AA is the stated reference criterion; these features do not certify the compliance of the integrating site or service. The applicable Italian legal reference for digital-service accessibility is [Law No. 4 of 9 January 2004 (Legge Stanca)](https://www.normattiva.it/eli/id/2004/01/17/004G0015/CONSOLIDATED/20231118).

<a id="limitazioni-note"></a>Known limitations: the modal focus trap is handled by Bootstrap Italia JavaScript and is not tested by this package; older screen readers may vary in how they announce errors associated with fieldsets; color contrast inherited from Bootstrap Italia 2.18.3 is not automatically checked in CI with axe-core or pa11y.

## Tests

Run from the package directory:

```bash
vendor/bin/phpunit
vendor/bin/pint --test
```

The suite covers component rendering, Laravel error and old-input binding, ARIA attributes, ID generation, publishing commands, and the asset Blade directives.
